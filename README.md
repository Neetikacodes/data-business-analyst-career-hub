# Data & Business Analyst Career Hub

Static site (HTML, CSS, vanilla JS). No build step, no backend.

## Files
`index.html`, `style.css`, `data.js` (all editable content), `script.js`, `README.md`

## Deploy on GitHub Pages
1. Create a repository named `data-business-analyst-career-hub`.
2. Upload all five files to the repository root.
3. Go to Settings → Pages.
4. Under Build and deployment choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
5. Open the published URL (shown on the Pages screen after a minute or two).
6. Click the three learning lab links, try the quiz, tick roadmap tasks and reload to confirm progress is saved.

## Updating salary data
Open `data.js`, find `salary`, and fill in `range`, `source`, `url`, `verified` (date you checked) and `notes`. A card shows numbers only when all four are present. Use reputable sources and note whether figures are base pay or CTC.

## Search visibility
After publishing, add a `sitemap.xml` listing your page URL and submit the site in Google Search Console. Indexing is not guaranteed.
